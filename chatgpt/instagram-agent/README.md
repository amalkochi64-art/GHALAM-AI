# GHALAM Instagram Agent for ChatGPT

This folder contains the ChatGPT-ready operating instructions for the GHALAM Instagram agent.

## Files
- SKILL.md: full reusable agent skill and operating rules.
- GPT_INSTRUCTIONS.md: compact instructions to paste into a Custom GPT or ChatGPT Project.
- CONNECTORS.md: verified integration capabilities and limitations.

## Use in ChatGPT
This repository commit does not install or activate a Custom GPT inside the user's ChatGPT account. To use it:
1. Open ChatGPT's GPT builder (or create a ChatGPT Project).
2. Paste GPT_INSTRUCTIONS.md into the Instructions field.
3. Upload SKILL.md and CONNECTORS.md as knowledge files if the builder supports files.
4. Enable only the connectors/actions you intend to use, then verify the target account and permissions.

## Verified integration state at preparation time
See CONNECTORS.md. Public posting and comment changes must be previewed and explicitly confirmed. Instagram DM access is not currently verified.
